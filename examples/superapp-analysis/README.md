# 超级应用与可选 AI 分析

[返回项目首页](../../README.md)

当你希望在页面中选择 AI 解释、按当前范围更新结论，或继续调用外部工具调查时，可以使用这套通用接入方案。普通模板和本地调查不依赖它。

## 接入方式

```text
超级应用页面
  → 观远请求转发网关
  → 私有分析服务
  → 可选 MCP / AI 服务
```

仓库提供前后端接口和示例，外部服务由使用者自行选择、配置与适配，没有默认连接模型。模型凭据保存在服务端，页面不携带模型密钥。MCP 是工具调用协议，本身不是模型。

支持手动更新、可选的 30 秒轮询、分组切换和调查执行；范围变化时清除旧结论，迟到的旧响应不会覆盖新结果。轮询不是实时推送。

## 运行合成演示

在仓库根目录，用当前受支持的 Node.js 运行（仓库 CI 使用 Node.js 22）：

```bash
node examples/superapp-analysis/server.cjs
```

打开终端打印的本地地址，默认是 `http://127.0.0.1:8766`。无需安装额外 npm 依赖。结束后按 `Ctrl+C` 停止服务。

1. 选择模板与分组，点击“更新分析”。
2. 执行量价、漏斗、渠道或阈值调查，查看带单位的结果和下一步建议。
3. 切换分组，确认旧调查已清除；按需打开自动刷新。
4. 未接入逐日数据时，调查按钮会提前说明缺少什么。

演示只包含合成数据。AI 模式默认不可选，不伪装模型返回；本地服务的演示身份也不是生产认证实现。

## 接入自己的服务

- 按实际官方 CLI 版本创建 SuperApp 工程，使用其构建与发布流程。
- 将 [`client.js`](../../skills/guanyuan-bi/assets/superapp/client.js) 接入前端，使用已确认的同源观远网关路由。
- 私有服务使用 [`service.cjs`](../../skills/guanyuan-bi/assets/superapp/service.cjs)，提供身份校验、范围授权和数据快照适配器。
- 可选 AI 能力由使用者提供 `provider`；使用 MCP 时接入已初始化的客户端及明确允许的分析工具。
- 分别验证用户的数据访问权限和 AI 数据使用范围。服务端返回证据、时间、版本及明确的能力状态。

具体字段、能力校验、错误处理和发布边界见 [超级应用接入契约](../../skills/guanyuan-bi/references/superapp-analysis.md)。静态应用上传不会同时部署后端服务，也不能将本示例直接视为观远可发布的资源包。

## 验证范围

本仓库验证通用接口、合成数据、模拟 MCP 返回及浏览器交互；没有验证任何使用者的真实模型或生产环境。引用存在不等于 AI 的解释正确，业务结论仍需依据证据判断。

AI 也可以在 Codex / Claude Code 任务中按 [分析流程](../../skills/guanyuan-bi/references/analysis.md) 执行。持续无人值守巡检与通知需要另行配置调度和交付策略。
