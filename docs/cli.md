# CLI 自动化

`guanyuan-cli` 是官方 CLI 的社区编排技能，可独立操作数据集和看板，也可作为 HTML Skill 的发布执行入口。

## 安装与检查

安装本仓库 `skills/guanyuan-cli` 的完整目录。然后让 AI 按技能的 [官方安装说明](../skills/guanyuan-cli/references/setup.md) 检查并安装所需组件。技能与 CLI 是两个安装层次；技能安装成功不等于 CLI 或登录成功。

安装后可在本仓库运行：

```bash
python3 skills/guanyuan-cli/scripts/doctor.py
python3 skills/guanyuan-cli/scripts/doctor.py --components guancli guands guanvis
```

已单独安装技能时，将脚本位置换成实际安装目录。脚本只调用所选组件的 `--help`，不登录、不读取业务数据、不修改看板；全部启动成功返回 0，否则返回 1。CLI 版本另按官方命令记录。

## 一次配置，按任务执行

配置见 [私有配置约定](../skills/guanyuan-cli/references/configuration.md)。用户本次要求优先，其次项目配置，再其次用户配置；没有内置业务默认值。配置由 AI 读取并转换为官方命令参数，不是官方 CLI 原生配置格式。密码和令牌使用官方认证存储。

只配置本次涉及的环境和资源。目录与数据源需要在目标实例查询确认。已有看板默认保持位置、连接和 ID，不受新建偏好影响。

## 使用示例

- “检查并安装观远 CLI，验证只读连接，不修改线上资源。”
- “按我确认的字段创建数据集，放到我指定的目录，回读验证结构。”
- “把当前 HTML 发布到指定观远目录，绑定已确认的数据集，并检查真实页面。”
- “修改已有 HTML 看板的布局，保持页面 ID 和数据口径，发布后验证。”

完整流程见 [交付与更新](../skills/guanyuan-cli/references/delivery.md)。当环境不支持某个操作时，交付说明应明确到具体行为和阶段，并保留已完成结果。

## 本次升级覆盖

- HTML 技能保留本地预览，同时增加自动平台交付路径。
- CLI 技能提供六组件路由、官方安装指导、私有配置契约和首次发布/同 ID 更新流程。
- 环境检查脚本及合成测试不依赖业务凭据。
- 血缘技能与原有示例保持兼容。

本仓库尚不提供跨服务器版本的在线发布认证。请在私有环境对首次 HTML 发布及同 ID 更新完成验收；反馈兼容性问题时只提交从零构造的复现材料。第三方组件以各自许可证为准。
