# v0.1.0-beta.1 · 首个公开试用版本

用 Codex / Claude Code 辅助设计、接入和维护观远 BI 看板，并梳理指标血缘。此版本用于收集真实用户体验反馈。

## 四套 Skill

| Skill | 用途 |
| --- | --- |
| guanyuan-bi | 统一入口，理解需求并协调设计、分析与交付 |
| guanyuan-html-bi-generic | HTML 看板设计、模板与字段适配 |
| guanyuan-cli | 编排观远官方 CLI，检查环境、接入数据、发布与维护 |
| guanyuan-metric-lineage | 梳理公式、筛选、联动和可见上游来源；CLI 优先，HAR 补充 |

## 本版新增

- 固定版本的完整下载包、技能清单及 SHA-256 校验。
- Codex / Claude Code 安装器，支持显式安装目录；升级备份，定制冲突不覆盖。
- 技能版本与文件自检，按任务检查官方组件，并支持隔离 CLI 目录。
- 私有项目初始化，保存页面源文件、字段映射、资源身份和验收状态。

## 开始使用

下载本页的 `guanyuan-bi-toolkit-0.1.0-beta.1.zip`，解压并阅读 `INSTALL.md`。安装后调用 `guanyuan-bi`，提供需求和字段说明。也可以直接调用血缘技能分析已有看板。

官方 CLI 独立安装，所需版本按用户实际环境适配。本项目版本号不代表观远官方组件版本。

## 验证范围

本版包含程序测试、合成数据测试、安装/升级/冲突保护、工程初始化及发布包校验。GitHub Actions 在 Ubuntu 24.04、Python 3.12、Node 22 上运行检查；本地安装工具也在临时目录中验证。

这些证据不等于真实用户验收。Codex / Claude Code 中的新用户完整任务、不同观远服务端上的首次发布与同 ID 更新，等待用户试用反馈。没有发布跨所有系统或服务端的兼容认证。

## 已知限制

- 安装器和配套 Python 工具需要 Python 3.9+；完整回归环境为 Python 3.12，其他组合待验证。
- CLI、本地技能与观远服务端分别更新。默认不会后台自动升级。
- 换成业务数据需要确认字段、口径和权限；初始化工程不会自动绑定真实数据集。
- 内置分析是数值比较和顺序分解；两个聚合周期不能证明逐日趋势或业务原因。
- 超级应用中的外接 AI / MCP 仅提供通用接口，需用户自行适配服务。
- 旧版没有清单或含本地定制时，安装器会保留原内容，需合并后再更新。
