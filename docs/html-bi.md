# 把示例接进观远

## 先本地预览

打开 `examples/html-bi/index.html`。页面只加载同目录的 CSS 和 JavaScript，不发起远程请求。

`mock-data.js` 提供合成数据；`dashboard.js` 同时负责本地渲染和观远适配。发布到观远时不要粘贴 `mock-data.js` 或本地演示按钮。

## 数据契约

本例只绑定一个数据集，固定为 `data[0]`。每行是一日、一门店的已汇总结果。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `day` | `YYYY-MM-DD` 字符串 | 统计日 |
| `store` | 字符串 | 门店标识或名称 |
| `orders` | 非负数字 | 当日门店订单数 |
| `sales` | 非负数字 | 当日门店销售额，演示使用虚构单位“星币” |

唯一键为 `day + store`。实际项目需自行确认订单去重、退款、时区与币种。本例中订单数和销售额可加；客单价必须按 `SUM(sales) / SUM(orders)` 计算，不对分组客单价取平均。

零订单时客单价显示 `—`；缺失值、负值、重复键和结构异常显示错误，避免默默转成零。

平台列式输入示例：

```javascript
[
  [
    { name: 'day', data: ['2099-01-01'] },
    { name: 'store', data: ['月球站'] },
    { name: 'orders', data: [40] },
    { name: 'sales', data: [600] }
  ]
]
```

## 手工接入步骤

1. 准备符合契约的数据集，核对字段名、粒度、单位和更新日期。
2. 在支持自定义图表的环境中绑定该数据集，保持在第一个位置。
3. 将 `dashboard.css` 放入 CSS 区；将 `dashboard.js` 放入 JavaScript 区。
4. 需要 HTML 容器时添加 `<div id="container"></div>`；平台已有该容器则复用。
5. 脚本会在 `GDPlugin` 可用时通过 `new GDPlugin().init(renderChart)` 注册。
6. 比对全部范围和每个门店的订单、销售额、客单价及每日趋势。

该适配器针对本说明中的列式结构。若实际输入形态不同，应调整 `columnsToRows`，不能凭位置猜字段含义。平台编辑器和插件 API 可能因版本、授权而异，需要在自己的环境中验证。

## 出问题时看哪里

| 现象 | 检查 |
| --- | --- |
| 空白 | 容器是否存在，脚本是否加载，`GDPlugin` 是否可用 |
| 显示“缺少数据集” | 是否绑定数据集，是否位于 `data[0]` |
| 显示“字段缺失” | 列名是否相同，列结构是否已更新 |
| 页面数值过大 | 是否重复汇总，`day + store` 是否唯一 |
| 改字段后仍旧报错 | 核对平台数据集结构及卡片绑定，再刷新数据 |

发布前用获准的实际数据在私有环境中验收。不要把验收数据或截图提交到这个公开仓库。

## 通过 CLI 自动接入

发布任务由 HTML Skill 按需衔接 `guanyuan-cli`，具体见 [CLI 指南](cli.md)。用官方 SDK 自定义图表模式加载平台 HTML/CSS/JS，并按数据契约顺序添加数据视图。不要发布 `mock-data.js`、本地预览启动代码或演示按钮。

CLI 结构预览不能替代平台渲染验收。发布后核对真实数据视图的字段、聚合、顺序和最终页面；后续保留同一页面与卡片 ID 进行更新。实例、目录和连接来自私有配置或用户要求，公共示例不含环境默认值。
